# 🎓 Sorbil Portfolio Projesi

Bu proje, **Sorbil Eğitim Kurumu** için eğitim amaçlı olarak hazırlanmış modern bir portfolio web uygulamasıdır. Proje, ASP.NET Core MVC mimarisi kullanılarak geliştirilmiştir.

## 🚀 Proje Özellikleri

### 🎯 Sayfalar
- **Ana Sayfa**: Kişisel tanıtım ve profil bilgileri
- **Hakkımda**: Detaylı kişisel bilgiler ve deneyimler
- **İletişim**: İletişim bilgileri ve sosyal medya linkleri
- **Admin Panel**: İçerik yönetimi ve güncelleme

## 🛠️ Kullanılan Teknolojiler

### Backend Teknolojileri
- **ASP.NET Core 6.0**: Modern web framework
- **C#**: Programlama dili
- **Entity Framework Core 6.0**: ORM (Object-Relational Mapping)
- **SQL Server**: Veritabanı yönetim sistemi
- **MVC Pattern**: Model-View-Controller mimarisi
